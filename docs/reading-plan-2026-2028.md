# Reading Plan 2026–2028

Three tracks read in parallel:

| Track | Daily target | Slot |
|---|---|---|
| Technical | ~20 pages | 12:15 iPad block |
| Non-technical | ~30 pages | Evening |
| Slow lane | ~10 pages | Morning coffee / weekends |

Rule: one active book per track. Start the next book only when the current one is finished, paused or dropped.

---

## Phase 1 — Foundations (Q4 2026)

**Goal:** sharpen your craft and testing, get a first map of architecture, and build focus habits.

**Technical**
1. Effective Java — Joshua Bloch *(finish; ideally 3rd edition)*
2. The Pragmatic Programmer — David Thomas & Andrew Hunt
3. Unit Testing Principles, Practices, and Patterns — Vladimir Khorikov
4. Fundamentals of Software Architecture — Mark Richards & Neal Ford

**Non-technical**
1. The Psychology of Money — Morgan Housel *(finish)*
2. Deep Work — Cal Newport
3. So Good They Can't Ignore You — Cal Newport

---

## Phase 2 — Distributed systems in production (Q1 2027)

**Goal:** reason about distributed trade-offs, design for failure, and see inside running systems; build resilience and perspective.

**Technical**
1. Software Architecture: The Hard Parts — Neal Ford, Mark Richards, Pramod Sadalage & Zhamak Dehghani
2. Building Microservices (2nd ed.) — Sam Newman
3. Release It! — Michael T. Nygard
4. Observability Engineering — Charity Majors, Liz Fong-Jones & George Miranda

**Non-technical**
1. The Obstacle Is the Way — Ryan Holiday
2. Meditations — Marcus Aurelius
3. Man's Search for Meaning — Viktor Frankl
4. 1984 — George Orwell

## Phase 3 — Data and domain (Q2 2027)

**Goal:** master persistence and security in your daily stack and model business domains well; understand how you think and what a good life means.

**Technical**
1. High-Performance Java Persistence — Vlad Mihalcea
   - *Optional:* SQL Performance Explained — Markus Winand
2. Learning Domain-Driven Design — Vlad Khononov
3. Domain-Driven Design — Eric Evans
4. Spring Security in Action (2nd ed.) — Laurențiu Spilcă

**Non-technical**
1. Thinking, Fast and Slow — Daniel Kahneman
2. How to Live a Good Life — Massimo Pigliucci, Skye Cleary & Daniel Kaufman (eds.)
3. Nicomachean Ethics — Aristotle
4. Cel mai iubit dintre pământeni — Marin Preda

## Phase 4 — JVM and messaging depth (Q3 2027)

**Goal:** understand how the JVM and Kafka really behave under load, and design systems that evolve safely; define your relationship with time, ambition and power.

**Technical**
1. Java Concurrency in Practice — Brian Goetz *(Part I closely; skim dated chapters; follow up with JEP 444 on virtual threads)*
2. Optimizing Java — Benjamin J. Evans, James Gough & Chris Newland
   - *Optional:* Troubleshooting Java — Laurențiu Spilcă
3. Kafka: The Definitive Guide (2nd ed.) — Gwen Shapira et al.
4. Building Evolutionary Architectures (2nd ed.) — Neal Ford, Rebecca Parsons & Patrick Kua

**Non-technical**
1. Four Thousand Weeks — Oliver Burkeman
2. Hiking with Nietzsche — John J. Kaag
3. Beyond Good and Evil — Friedrich Nietzsche
4. The Prince — Niccolò Machiavelli
5. Minima moralia — Andrei Pleșu
